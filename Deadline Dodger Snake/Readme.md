# Deadline Dodger Snake

Collect study points. Avoid deadlines.

## Overview

Deadline Dodger Snake is a terminal-based snake game written in Python. The player controls a student-themed snake that collects study points while avoiding crashing into itself.

The game includes:
- Score tracking
- High score saving
- Restart system
- High score reset
- Screen wrapping mechanics

This project demonstrates Python concepts taught in COMP9001, including:
- Loops
- Functions
- Lists and tuples
- File input/output
- Exception handling
- Random generation

---

## How to Run

Make sure Python 3 is installed.

Run:

```bash
python main.py
```

---

## Controls

- W = Up
- A = Left
- S = Down
- D = Right

Press Enter after each move.

---

## Files

- `main.py` → main game
- `high_score.txt` → stores high score
- `test_snake.py` → simple testing script
